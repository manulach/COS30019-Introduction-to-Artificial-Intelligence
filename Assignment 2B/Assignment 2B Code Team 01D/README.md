## How to Run

All commands are run from the `Assignment2B/` folder.

### Step 1 — Process the data (run once)
```
python data_processor.py
```
Reads `data/Scats Data October 2006.xls`, cleans the data, builds sequences, and saves `.npy` arrays and a `scaler.pkl` to the `data/` folder.

### Step 2 — Train the ML models (run once)
```
python train_models.py
```
Trains LSTM, GRU, and CNN-LSTM models. Saves trained models to `models/` and evaluation plots to `results/`. Takes approximately 5–15 minutes depending on your machine.

### Step 3 — Launch the GUI
```
python gui.py
```
Opens the full TBRGS application. You can also run Steps 1 and 2 from inside the GUI using the **Process Data** and **Train ML Models** buttons.

## GUI Guide

| Control | Description |
|---|---|
| **Process Data** | Runs `data_processor.py` — required before training |
| **Train ML Models** | Trains all 3 models — runs in background, progress bar shows activity |
| **Origin / Destination** | Select SCATS site by ID and location name |
| **Time of day** | Choose any 15-minute interval (00:00–23:45) |
| **Prediction model** | LSTM, GRU, or CNN_LSTM — determines which model provides flow predictions |
| **Number of routes (k)** | 1 to 5 alternative routes |
| **Find Top-k Routes** | Runs Yen's algorithm and displays results in the Routes tab |
| **Routes tab** | Ranked routes with travel time, path, and per-hop traffic conditions |
| **Traffic Chart tab** | Predicted vs actual traffic flow for the selected origin site |
| **Model Metrics tab** | MAE, RMSE, MAPE comparison across all three models |

## Configuration

Default settings are stored in `config.json` and loaded at startup. You can edit this file to change the default origin, destination, model, time interval, or window size.

---

## Part A Integration

`search.py` from Assignment 2A is included unchanged. The route finder (`route_finder.py`) extends Part A's A* algorithm to operate on the real Boroondara SCATS network, replacing abstract node IDs with SCATS site IDs and static edge costs with ML-predicted travel times.
